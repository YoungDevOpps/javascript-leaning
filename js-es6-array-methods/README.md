# js-es6-array-methods – Manipulation de tableaux avec les méthodes natives

Même exercice que [`js-es6`](../js-es6), mais résolu avec les méthodes de
tableau d'ES6 (`forEach`, `find`, `filter`, `map`, `reduce`) au lieu des
boucles `for` classiques. Les jeux de données (`numbers`, `students`,
`products`) sont identiques.

Consigne complète : [`instruction.md`](instruction.md).

## Fichiers

| Fichier | Thème | Méthode principale |
| --- | --- | --- |
| [`1-iteration.js`](1-iteration.js) | Itération | `forEach` |
| [`2-finding-elements.js`](2-finding-elements.js) | Recherche | `find` |
| [`3-filtering.js`](3-filtering.js) | Filtrage | `filter` |
| [`4-transforming.js`](4-transforming.js) | Transformation | `map` |
| [`5-aggregation.js`](5-aggregation.js) | Agrégation | `reduce` (+ `filter`) |

## Lancer un fichier

```bash
node 1-iteration.js
```
