# js-es6 – Manipulation de tableaux

Exercice sur les opérations courantes appliquées à des tableaux et des
tableaux d'objets. Les mêmes jeux de données (`numbers`, `students`,
`products`) sont réutilisés dans chaque fichier.

Consigne complète : [`instruction.md`](instruction.md).

## Fichiers

| Fichier | Thème | Contenu |
| --- | --- | --- |
| [`1-iteration.js`](1-iteration.js) | Itération | Parcourir un tableau, afficher chaque élément et chaque étudiant |
| [`2-finding-elements.js`](2-finding-elements.js) | Recherche | Premier nombre > 15 ; `getStudentById(id)` |
| [`3-filtering.js`](3-filtering.js) | Filtrage | Nombres pairs ; étudiants admis / recalés ; produits en stock |
| [`4-transforming.js`](4-transforming.js) | Transformation | Nombres doublés ; noms des étudiants ; prix TTC (+19 %) |
| [`5-aggregation.js`](5-aggregation.js) | Agrégation | Somme des nombres ; moyenne des notes ; total des produits en stock |

## Lancer un fichier

```bash
node 1-iteration.js
```
