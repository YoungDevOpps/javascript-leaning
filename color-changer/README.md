# Interactive Color Changer

Checkpoint GoMyCode — une page qui change la couleur d'une boîte à chaque clic.

## Structure

- `index.html` — heading, boîte `#color-box`, bouton `#change-color-btn`
- `style/style.css` — mise en forme (conteneur centré, boîte fixe, bouton)
- `js/script.js` — `getRandomColor()` + écouteur de clic sur le bouton

## Utilisation

Ouvrir `index.html` dans un navigateur et cliquer sur **Change Color**.
