# javascript-leaning

Petits projets et exercices réalisés pendant l'apprentissage de JavaScript
à GoMyCode. Chaque dossier est un projet autonome avec son propre `README`.

## Projets

| Dossier | Description |
| --- | --- |
| [`exercices-fonctions/`](exercices-fonctions/) | Exercices sur les fonctions : manipulation de chaînes, opérations sur les tableaux, fonctions mathématiques |
| [`js-es6/`](js-es6/) | Manipulation de tableaux : itération, recherche, filtrage, transformation, agrégation |
| [`js-es6-array-methods/`](js-es6-array-methods/) | Même exercice que `js-es6`, résolu avec `forEach`, `find`, `filter`, `map`, `reduce` |
| [`dom_projects/`](dom_projects/) | Projets DOM — [`project_1`](dom_projects/project_1/) : panier d'achat interactif (quantité, suppression, like, prix total) |
| [`shoping-card/`](shoping-card/) | Panier d'achat (version publiée) : chemins relatifs, structure HTML/CSS/JS séparée |
| [`color-changer/`](color-changer/) | Checkpoint « Interactive Color Changer » : bouton qui change la couleur d'une boîte via `getRandomColor()` |

## Prérequis

[Node.js](https://nodejs.org/) pour exécuter les scripts (`node fichier.js`).
Aucune dépendance externe.

## Organisation

Le dépôt regroupe plusieurs projets dans un seul repo. Un nouveau projet
= un nouveau dossier + son `README.md` + une ligne dans le tableau ci-dessus.
Pour publier un dossier, ajouter `!nom-du-dossier/` dans [`.gitignore`](.gitignore).
